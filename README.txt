# 🎬 TDownTloader - YouTube Video Downloader

A professional, web-based YouTube video downloader with multiple quality options (360p to 1080p). Built with Python Flask and yt-dlp.

## ✨ Features

- 🎯 **Multiple Qualities** - 360p, 480p, 720p, 1080p
- 🎨 **Modern Dark UI** - Beautiful glass-morphism design
- ⚡ **Fast Downloads** - Optimized with yt-dlp
- 🔧 **FFmpeg Support** - Full HD video with audio
- 📱 **Responsive Design** - Works on mobile & desktop
- 💾 **Auto-Save** - Videos saved locally
- 🚀 **Real-time Status** - Live download progress

## 🛠️ Tech Stack

- **Backend**: Python Flask
- **Frontend**: HTML5, CSS3, JavaScript
- **Download Engine**: yt-dlp
- **Video Processing**: FFmpeg (for 1080p)

## 📋 Prerequisites

- Python 3.8 or higher
- pip (Python package manager)
- FFmpeg (for 1080p downloads)
